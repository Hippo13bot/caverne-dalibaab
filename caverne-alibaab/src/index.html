    Non configuré · les données restent enregistrées localement.

    Installation de Supabase (une seule fois)

    Dans Supabase, crée un projet puis ouvre SQL Editor et exécute le SQL fourni dans docs/SUPABASE.sql. Active la confirmation d’e-mail si tu le souhaites, crée ton compte ici, puis connecte Mac et iPhone avec le même compte. Copie l’URL du projet et la clé publique dans les champs ci-dessus.

    La clé secrète « service_role » ne doit jamais être utilisée dans l’application.

    Importer (cloud)
