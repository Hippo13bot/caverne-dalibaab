# Guide utilisateur : La caverne d'Alibaab

## Sur iPhone
1. Ouvre l'adresse de l'app dans **Safari**, touche **Partager** ▸ **Sur l'écran d'accueil**. L'icône (image fixe de la mascotte) apparaît.
2. Ouvre l'app depuis l'icône : elle marche sans réseau.
3. **＋ Ajouter du matériel** : touche « Photo du matériel » pour prendre la photo directement, puis remplis la fiche.
4. **QR code** sur une fiche : imprime l'étiquette, colle-la sur le matériel. Scanner l'étiquette avec l'appareil photo de l'iPhone ouvre la fiche.
5. Barre du bas : **Mon inventaire**, **Mes sacs & kits**, **Exports & impressions**.
6. **Sauvegarder** : envoie le fichier JSON par AirDrop, Fichiers ou Mail. **Restaurer** le charge sur un autre appareil.

## Sur Mac / Windows
Même fonctionnement, dans l'application installée.

## Au quotidien
- États : en stock, emprunté / sorti (détenteur + retour prévu), indisponible (réparation, perdu, hors service).
- Pour Notion : **Exports ▸ CSV**, puis import en base de données.
- Fais une sauvegarde avant de changer d'appareil ou après une grosse saisie.
